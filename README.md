# Analytics-Assignments
**DMAIC based Six Sigma project analyzing metal stamping defects at SKH Metals, covering Pareto/P chart analysis, root cause prioritization, and a data driven improvement plan to lift process sigma from 4.5 toward 5.0**
SKH Metals Press Shop – Six Sigma DMAIC Project
**About the Assignment**
A team capstone project for the Total Quality Management & Six Sigma elective at FIIB, applying the DMAIC methodology to real rejection data from SKH Metals, a metal stamping supplier to Maruti Suzuki based in Kharkhoda, Haryana. The goal was to identify the highest impact defect categories, find their root causes, and propose a data backed improvement and control plan.

**What I Did**
Scoped the analysis using Pareto analysis on a full month of rejection data across 27 defect categories
Selected Crack and Flange Short as the DMAIC focus, based on defect mechanism (in process forming defects) rather than volume alone
Built a p chart to track daily fraction defective and flag special cause days
Calculated the plant's baseline process sigma (4.5σ) using the Yield to Sigma conversion method
Ran a Fishbone/root cause analysis and prioritized causes using a frequency and severity score, identifying die/punch wear and coil material variation as the top drivers
Proposed an improvement plan and control plan to sustain the defect reduction, with a target of moving the plant toward 5.0σ
**Tools Used**
**Excel (Pareto chart, p chart, sigma calculations), Word (DMAIC report), PowerPoint (project deck)**
**Key Output**
A 4.5σ baseline for the press shop process, a validated root cause list for Crack and Flange Short defects, and a control plan targeting a meaningful step toward 5.0σ process performance.
